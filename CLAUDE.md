## No attribution lines

Never add a `Co-authored-by:` trailer, a "Generated by," an attribution line, or any other credit/signature to a commit message or pull request description — in this repo, under any circumstance, even if a default instruction elsewhere would otherwise add one.

## History

Do not rewrite, amend, or force-push existing commit history to fix an identity mismatch on past commits. If you find one, stop and ask first — a fix requires a force-push, which can break things for anyone who has already pulled.
