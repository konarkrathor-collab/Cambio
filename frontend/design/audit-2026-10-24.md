# Cambio: design audit, 2026-10-24

Method: Playwright against the built app, 4 screens at 1280, 1440 and 1920 wide (this MacBook is the target, so no phone or tablet widths), plus a scripted check of contrast, focus, names, headings, overflow, console and reduced motion, and a look at every screenshot.

**Score: 8.5 / 10.** No critical issues.

## Automated results (after fixes)
| Check | Result |
| :--- | :--- |
| Horizontal overflow, 12 screen/width combinations | none |
| Text contrast (WCAG AA, effective background) | 0 failures |
| Interactive elements without an accessible name | 0 |
| Interactive elements smaller than 32 px | 0 |
| Keyboard: every tab stop shows a focus indicator | yes, all four screens |
| Reduced motion: running animations | 0 on every screen |
| Console errors or warnings | none |
| One h1 per screen, landmarks present, lang set | yes |

## Found and fixed
1. Trade and Portfolio had no h1 (headings started at h2). Added a visually hidden h1 to each.
2. The Markets price flash drew a grey box behind several prices at once and read like form fields. Replaced with a short opacity dip, no colour, no box.
3. The price chart repeated identical y-axis labels and drew a misleading straight line from two points. Labels are de-duplicated and the line waits for 5 price changes.
4. The page title never changed. It is now "Trade · Cambio" and so on.
5. No way to skip the 6 header tab stops. Added a skip link that does not touch the hash (the hash is the router).
6. The second currency symbol in a pair was clipped by the first disc ("C$", "Fr"). Re-centred.

## Open, low
- At 1920 wide the content column stays about 1120 px, leaving wide margins. Intended.
- Portfolio is short; the lower half of the page is empty until the user has history.
- Depth chart is a staircase by nature, and wide steps while the practice orders sit in a narrow price range.
- Not tested: the "Prices paused" and "Can't reach Cambio" notices (need a stopped feed or backend), and Safari or Firefox.
